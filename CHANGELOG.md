# Changelog

## 1.0.0

- Copy files and folders with a project tree as Markdown, XML or plain text.
- Copy Selected Tabs, Copy Project Structure, Copy Source Control File Contents and Copy Changes (git diff against HEAD, untracked files as new-file diffs).
- Repeat Last Copy and Force Copy Without Exclusions (cancellable).
- Exclusions: dot files, root `.gitignore`, `promptpack.exclude`, `promptpack.excludeContentPatterns`; placeholders for binary, oversized and non-UTF-8 files.
- Offline token counting with a configurable warning threshold.
- Trust-aware settings and migration of the deprecated exclude settings.
